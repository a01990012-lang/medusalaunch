# Medusa IV — Blue Launch

Landing page estática para GitHub Pages. No requiere compilación ni dependencias.

## Publicación
1. Extrae este ZIP en un repositorio de GitHub.
2. En **Settings → Pages**, selecciona la rama y la carpeta `/ (root)`.
3. Guarda y espera a que GitHub Pages publique el sitio.

## Personalización
- La fecha del contador se define en `script.js` (`2026-11-30T23:59:59-07:00`). Está configurada al cierre del 30 de noviembre, hora de Culiacán, porque los materiales ubican la ventana oficial entre el 23 de noviembre y el 4 de diciembre, pero no especifican hora exacta.
- El sonido se inicia únicamente tras pulsar **AUDIO OFF** o un botón de secuencia. El navegador controla voces disponibles para “Ignition, 5, 4, 3, 2, 1 / Liftoff”.
- Fotos, identidad gráfica y clip de ensayo están en `assets/`.
